# Poltic

Poltic is a web application aimed at delivering latest news to people in the form of short videos. Users can create a channel and upload their own content as well view others' content.

## 🌐 Live Demo

[Click here to see it live](https://poltic.in)

## 📂 Project Structure

- `/src`: Source code files
- `/public`: Public assets
- `README.md`: Project documentation
- `package.json`: Project metadata and dependencies

## 🛠 Features

- User Authentication
- Create Profile
- Upload Videos
- Scroll Videos
- Responsive Design

### 🧑‍💻 User Flow (App Usage)

* **Login / Signup**
  * Create a new account using email and password
* **Email Verification**
* **Login using email/password**
* **Reset Password**
* **Create and manage your profile**
* **Dashboard Access**
  * View/Create/Edit/Delete content (e.g., posts)
* **Logout**

### Prerequisites

Make sure you have these installed:

- [Node.js](https://nodejs.org/)
- npm or yarn

### Installation

```bash
git clone https://github.com/Muskan-Sinha/poltic.git
cd your-repo-name
npm install
npm start
```
